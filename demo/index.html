action

update: conservative

topology

scene 03 - ddsketch (p50 / p90 / p99?)

vs exact oracle

exact sorted array: running (allocates)

Each add(value) increments ONE log-scale bin. The exact oracle is a sorted Float64Array capped at N=100000 to keep the tab alive -- the sketch would keep going in the SAME fixed memory. min/max stay EXACT; only the quantiles are alpha-approximate.

action

When the bins fill, the SMALLEST values collapse into the floor bin (collapsed = false) -- the high tail (p90 / p99) stays alpha-accurate; only the smallest values degrade.

topology

alpha drives gamma = (1+a)/(1-a), the bin count, the memory, and the HARD error band. Sketch memory is a FIXED 16.0 KB whatever N is.
